1.1 · Mục tiêu & bản chất

Unit 42 dừng ở is done / was done. Unit này mở rộng bị động ra mọi thì và cấu trúc còn lại. Nguyên tắc không đổi: be (ở dạng phù hợp) + V3. Chỉ cần biết "be" trong cấu trúc đó có hình dạng gì: be, been hay being.

Somebody is repairing the lift. → The lift is being repaired.
Somebody has repaired the lift. → The lift has been repaired.
Somebody will repair the lift. → The lift will be repaired.

1.2 · Công thức cốt lõi

Sau modal / to: (to) be + V3 can be done, will be done, to be done Modal + perfect: (to) have been + V3 should have been done, might have been done Present perfect: have / has been + V3 has been done Past perfect: had been + V3 had been done Present continuous: am / is / are being + V3 is being done Past continuous: was / were being + V3 was being done

1.3 · A. Be done (sau modal, to, going to)

  • Something must be done before it's too late.
  • A mystery is something that can't be explained.
  • I want to be left alone. (to + be + V3)

1.4 · B. Have been done (modal + perfect)

  • Nói về quá khứ với ý suy đoán / nên / có thể: The parcel might have been sent to the wrong address.
  • Trong câu điều kiện loại 3: If you had locked the car, it wouldn't have been stolen.
  • Sau seem/appear: The problems seem to have been solved.

1.5 · C. Has been done / had been done

  • Have you heard? The match has been cancelled. · Have you ever been bitten by a dog?
  • The soup tasted awful. It had been cooked too long. (trước một thời điểm quá khứ)

1.6 · D. Is being done / was being done

  • Đang bị/được làm tại thời điểm nói: I think we are being followed. · (in a shop) No thanks, I'm being served.
  • Đang bị/được làm tại một thời điểm quá khứ: The room was being cleaned when I arrived.

2.1 · 8 ví dụ thực tế (đời sống · công việc · thi cử)

🚧 A new metro line is being built in Ho Chi Minh City. (tin tức — đang thi công)
✈️ Your flight has been delayed by two hours. (sân bay — thông báo)
📧 The report must be sent before Friday. (công việc — yêu cầu)
🔐 This door should be kept closed at all times. (biển báo — quy định)
🛍️ — Can I help you? — No thanks, I'm being served. (mua sắm — câu lịch sự)
📬 The letter might have been sent to my old address. (đời sống — suy đoán quá khứ)
🍲 The fish didn't taste good. It had been left out of the fridge. (đời sống — quá khứ hoàn thành)
📊 More money should be spent on public transport. (IELTS Writing — đề xuất giải pháp)

2.2 · Mẹo ghi nhớ 🧠

  • Công thức "chèn BE": lấy câu chủ động, giữ nguyên phần trợ động từ, rồi chèn be/been/being + V3: will clean → will be cleaned; has cleaned → has been cleaned; is cleaning → is being cleaned.
  • been ↔ have, being ↔ be: sau have/has/had là been; sau am/is/are/was/were là being.
  • Modal + be + V3: can be, must be, should be, will be — không bao giờ bỏ "be".

2.3 · Mẹo làm bài thi 🎯

  • Thấy right now / at the moment + chủ ngữ là vật → is/are being + V3.
  • Thấy already / just / ever / since / for + bị động → has/have been + V3.
  • Thấy by now / a long time ago sau should/might → should/might have been + V3.
  • Câu viết lại với they / somebody: giữ nguyên thì, chỉ đổi sang bị động.
  • Các tính từ đuôi -able / -ible = can be + V3: washable, edible, portable.

2.5 · Áp dụng vào nói & viết hàng ngày ✍️

  • Cập nhật tiến độ công việc: The design has been approved. The code is being tested. It will be released next week.
  • IELTS Writing Task 2: đề xuất giải pháp bằng should be + V3 / must be + V3.
  • Quan sát xung quanh: mỗi ngày tìm 3 thứ đang được làm (is being built/repaired…) và 3 thứ đã được làm (has been painted…).
