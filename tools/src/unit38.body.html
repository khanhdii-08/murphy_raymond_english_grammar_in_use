1.1 · Mục tiêu & bản chất

Cùng nói về hiện tại/tương lai, nhưng có hai cách: If I do …, I will … khi việc đó có thể xảy ra thật; If I did …, I would … khi ta chỉ tưởng tượng (không xảy ra hoặc không mong nó xảy ra). Động từ ở vế if là quá khứ, nhưng nghĩa không phải quá khứ.

(Chưa quyết định) If we go by bus, it will be cheaper.
(Đã quyết đi tàu) If we went by bus, it would be cheaper.
Câu 1: đi xe buýt vẫn có thể. Câu 2: biết chắc là không đi xe buýt → tưởng tượng.

1.2 · Công thức cốt lõi

Có thể xảy ra: If + hiện tại đơn, will / can / may + V If you find my watch, can you call me? Tưởng tượng: If + quá khứ đơn, would / could / might + V If you found a wallet, what would you do? be: If I / he / she / it was hoặc were Không dùng would trong vế if (trừ lời nhờ trang trọng: I'd be grateful if you would …)

1.3 · A. So sánh: if we go / if we went

  • Người nói thấy việc đó vẫn có thể → If we go …, it will …
  • Người nói biết việc đó sẽ không xảy ra → If we went …, it would … (không nói If we go)

1.4 · B. If + quá khứ = tưởng tượng (nghĩa không phải quá khứ)

  • What would you do if you won a lot of money? (không thực sự mong sẽ trúng)
  • If there was / were an election tomorrow, who would you vote for? (xem Unit 39C)
  • So sánh: If you find my watch, can you call me? (có thể tìm thấy) ≠ If you found a wallet in the street, what would you do? (tưởng tượng)

1.5 · C. Không dùng would trong vế if

I'd be very scared if somebody pointed a gun at me. (not: if somebody would point) If we went by bus, it would be cheaper. (not: If we would go) Ngoại lệ — lời nhờ trang trọng: I would be grateful if you would let me know your decision.

1.6 · D. Vế chính: would / could / might

  • If I went to bed now, I wouldn't sleep. · Would you mind if I used your phone?
  • If I won a lot of money, I might buy a house. (có thể sẽ)
  • If it stopped raining, we could go out. (= would be able to)

1.7 · Dấu hiệu nhận biết

Dấu hiệuChọn

Chỉ đường, hướng dẫn, việc thường gặp: "I often see her"If + hiện tại, will

2.1 · 8 ví dụ thực tế (đời sống · công việc · thi cử)

🎰 If I won the lottery, I'd buy my parents a house. (tưởng tượng — IELTS Speaking)
🗺️ If you turn left at the lights, you'll see the museum. (chỉ đường — thực tế)
⌚ If you find my glasses, can you call me? (có thể xảy ra)
👛 If you found a wallet in the street, what would you do? (câu hỏi giả định)
🚗 I can't afford a car. If I bought one, I'd have to borrow money. (đời sống — lý do không làm)
☔ If it stopped raining, we could go for a walk. (could = would be able to)
📨 I would be grateful if you would reply by Friday. (email trang trọng — ngoại lệ would trong vế if)
🤝 Would you mind if I opened the window? (xin phép rất lịch sự)

2.2 · Mẹo ghi nhớ 🧠

  • "Lùi một thì = lùi khỏi thực tế": hiện tại → quá khứ (vế if), will → would (vế chính).
  • Vế if không có would — would chỉ ở vế còn lại.
  • Hỏi bản thân: "Có thể xảy ra thật không?" Có → If I do / will. Không / khó → If I did / would.
  • If I were you, … là mẫu câu khuyên kinh điển (Unit 39).

2.3 · Mẹo làm bài thi 🎯

  • Đề cho trước "We've decided not to …" → viết If we + V-ed …, we'd … (không phải if we go).
  • Chia 2 vế: thấy would ở một vế → vế có if phải là quá khứ đơn.
  • Đáp án có If … would … (trừ "grateful if you would") → loại.
  • Với I/he/she/it: was và were đều đúng; trong văn trang trọng ưu tiên were.

2.5 · Áp dụng vào nói & viết hàng ngày ✍️

  • Nói (2 phút/ngày): trả lời 3 câu "What would you do if…?" (trúng số, mất điện thoại, được nghỉ 1 tháng).
  • Giải thích lý do không làm: "I'm not going to move. If I moved, I'd have to find a new school for my kids."
  • Email công việc: "I would be grateful if you would confirm the meeting time."
  • IELTS Speaking Part 3: "If the government invested more in public transport, fewer people would drive."
  • Quy tắc vàng: thật → If I do; tưởng tượng → If I did.

🔁 Ôn tập cách quãng: làm lại phần bài tập sau 3 ngày, 7 ngày và 14 ngày; mỗi lần ưu tiên "Làm lại câu sai". Liên quan: Unit 25 (if và when), Unit 36 (would), Unit 39 (If I knew / I wish), Unit 40 (If I had known).
