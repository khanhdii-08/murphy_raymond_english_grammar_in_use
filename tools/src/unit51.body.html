1.1 · Mục tiêu & bản chất

Trợ động từ (auxiliary verbs) như be, have, do, can, will, should, would... "giúp" động từ chính tạo thì, câu hỏi, phủ định. Trong giao tiếp, người bản xứ dùng trợ động từ một mình để khỏi lặp lại cả câu: trả lời ngắn, phản bác, tỏ ra quan tâm, đồng tình (So do I), và các câu I think so / I hope not.

"Have you locked the door?" — "Yes, I have." (= I have locked the door)
Gary wasn't working, but Laura was.
Trợ động từ thay cho cả cụm động từ đã nói trước đó.

1.2 · Công thức cốt lõi

Trợ ĐT trong câu → dùng lại chính nó: can → can, have → have, was → was Hiện tại / quá khứ đơn (không có trợ ĐT) → do / does / did Trả lời ngắn / phản bác : Yes, I have. / No, I'm not. / Yes, I did! Tỏ ý quan tâm : Have you? / Isn't she? / Did it? Đồng tình (+) : So + trợ ĐT + S So am I. / So did Paul. Đồng tình (−) : Neither/Nor + trợ ĐT + S Neither do I. / Nor can I. = S + trợ ĐT phủ định + either I don't either. think/hope ... : I think so. / I hope not.

1.3 · A. Trợ động từ thay cho cả cụm

  • Jessica could lend me the money, but she won't. (= won't lend me the money)
  • Hiện tại/quá khứ đơn dùng do/does/did: "Do you like onions?" "Yes, I do." / "Does Simon live in London?" "He did, but he doesn't any more."

1.4 · B. Phản bác (deny)

Dùng trợ động từ ngược với câu của người kia, thường nhấn giọng mạnh:

"You're sitting in my place." — "No, I'm not." "You didn't lock the door." — "Yes, I did!" "You never listen to me." — "Yes, I do!"

1.5 · C. Tỏ ra quan tâm / ngạc nhiên: Have you? Isn't she?

  • "I've just seen Stephen." — "Oh, have you? How is he?"
  • "Lisa isn't very well today." — "Oh, isn't she? What's wrong?"
  • "It rained every day." — "Did it? What a shame!"

Câu khẳng định → hỏi lại khẳng định (have you?); câu phủ định → hỏi lại phủ định (isn't she?). Khác với câu hỏi đuôi (Unit 52)!

1.6 · D. So / Neither / Nor (đồng tình)

  • So + trợ ĐT + S (câu khẳng định): "I'm tired." "So am I." / I passed and so did Paul. (không nói so Paul did)
  • Neither/Nor + trợ ĐT + S (câu phủ định): "I never read newspapers." "Neither do I."
  • Hoặc S + trợ ĐT phủ định + either: "I don't know." "I don't either."
  • Lưu ý: sau Neither dùng trợ ĐT khẳng định (Neither do I, không Neither don't I).

1.7 · E. I think so / I hope so / I'm afraid not...

Khẳng địnhPhủ định thông dụng
I think so / I expect soI don't think so / I don't expect so
I hope so / I'm afraid so / I guess soI hope not / I'm afraid not / I guess not

⚠️ "Do you think it will rain?" — "I hope not." (không nói I don't hope so). I'm afraid so/not = tiếc là có/không (tin xấu).

2.1 · 8 ví dụ thực tế (đời sống · công việc · thi cử)

☕ "I need a coffee." — "So do I." (văn phòng — đồng tình)
🎤 "I can't sing at all." — "Neither can I." (karaoke — đồng tình phủ định)
✈️ "I've just come back from Japan." — "Oh, have you? How was it?" (giao tiếp — tỏ ra quan tâm)
🔒 "You didn't lock the door." — "Yes, I did!" (gia đình — phản bác)
☔ "Is it going to rain?" — "I hope not." (đời sống — hope not)
🏨 "Have you got a room for tonight?" — "I'm afraid not. We're full." (dịch vụ — báo tin xấu lịch sự)
📈 "Will we get a bonus this year?" — "I expect so." (công việc — dự đoán)
🎓 Minh passed the exam and so did his sister. (thi cử — đảo ngữ sau so)

2.2 · Mẹo ghi nhớ 🧠

  • "Soi trợ động từ": câu gốc dùng trợ ĐT nào thì đáp lại bằng trợ ĐT đó; không có thì dùng do/does/did đúng thì.
  • So/Neither + ĐẢO: So am I, Neither do I — giống trật tự câu hỏi.
  • Neither đã mang nghĩa phủ định → trợ ĐT sau nó để khẳng định.
  • hope / afraid / guess → "not"; think / expect → "don't ... so".
  • Have you? / Did it? = "Thật à?" — giữ nguyên dạng khẳng/phủ định của câu người kia.

2.3 · Mẹo làm bài thi 🎯

  • Điền trợ ĐT: đọc vế đầu để biết thì và khẳng/phủ định, vế sau thường ngược lại: I wasn't tired, but my friends were.
  • Thấy "but" → thường đổi khẳng ↔ phủ định.
  • Câu có never, hardly, nobody là câu phủ định → đồng tình bằng Neither: "I never eat meat." "Neither do I."
  • Câu có 'd: I'd like = I would → So would I; I'd seen = I had → So had I.
  • Tin xấu xác nhận → I'm afraid so; tin xấu phủ nhận (từ chối) → I'm afraid not.

2.5 · Áp dụng vào nói & viết hàng ngày ✍️

  • Nói chuyện phiếm: mỗi khi bạn bè kể gì, thử phản hồi bằng Did you? / Have you? / Is it? + một câu hỏi tiếp — giúp hội thoại tự nhiên hơn.
  • Đồng tình nhanh: thay "Me too" bằng So do I / So am I / Neither can I để luyện phản xạ chọn trợ ĐT.
  • Công việc: trả lời câu hỏi chưa chắc chắn: "I think so, but let me check." / "I don't think so."
  • Quy tắc vàng: khi đáp lại, tự hỏi "Câu kia dùng trợ ĐT gì, thì gì, khẳng hay phủ định?"
